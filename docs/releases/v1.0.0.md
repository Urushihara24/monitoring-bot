# v1.0.0 — Stable public release

This release marks the first stable public version of the GGSEL + DigiSeller marketplace automation runtime.

## Highlights

- multi-profile GGSEL and DigiSeller marketplace automation;
- competitor monitoring with parser fallbacks and persisted diagnostics;
- configurable follow / undercut / raise / showcase pricing strategies;
- fail-closed `DRY_RUN` boundary for marketplace price and chat writes;
- idempotent seller updates with post-write verification;
- Telegram operational controls and diagnostics;
- SQLite runtime state, history and per-product settings;
- credential-free pricing simulator and fake marketplace runtime;
- Docker Compose deployment, health checks and hardened non-root runtime path;
- Python 3.11 / 3.12 CI, pytest, Ruff, dependency audit and secret scanning;
- contributor, security, architecture and operations documentation.

## Safe evaluation

The project can be evaluated without seller credentials:

```bash
python3 scripts/demo_pricing.py
python3 scripts/demo_runtime.py
```

Both demo paths perform zero marketplace writes. New full-runtime configurations start with `DRY_RUN=true`.

## Upgrade / deployment note

Existing deployments that do not define the newer safety/configuration variables retain their documented compatibility behavior. Review `CHANGELOG.md`, `DEPLOY.md` and `docs/DRY_RUN.md` before changing an existing production deployment.

## Known post-v1 work

The stable runtime is released with further maintainability work tracked separately, primarily modularization of the largest orchestration modules and additional container lifecycle verification. These items do not block the v1 safety/runtime acceptance criteria.
