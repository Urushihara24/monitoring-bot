# v1.0.1 — Maintenance and dependency refresh

This maintenance release refreshes the verified runtime and CI toolchain without changing pricing formulas, marketplace write semantics, `DRY_RUN` behavior, persisted-state meaning, or deployment defaults.

## Updated

- `actions/setup-python` 6 → 7;
- `actions/checkout` 5 → 7;
- `python-telegram-bot` 22.7 → 22.8;
- `pytest-asyncio` 1.2.0 → 1.4.0;
- `beautifulsoup4` 4.12.3 → 4.15.0;
- `ruff` 0.14.0 → 0.17.0.

Dependabot configuration now groups only lower-risk development and GitHub Actions minor/patch updates. Production/runtime Python dependencies remain isolated so parser, API, Telegram, and write-path changes continue to receive focused review.

## Verification

Runtime-sensitive updates were reapplied on the current v1 branch and merged only after the repository quality gates passed:

- Python 3.11 / 3.12 test matrix;
- parser and scheduler regression coverage;
- Docker root and non-root image validation;
- credential-free fake marketplace runtime;
- dependency audit and tracked-secret checks;
- Ruff critical-rule and compile verification.

## Compatibility

No configuration migration is required from v1.0.0. Existing production deployments should retain their documented behavior. New configurations continue to start with `DRY_RUN=true`.
